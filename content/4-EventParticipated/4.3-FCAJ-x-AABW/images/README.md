![Our team pitching](/4-eventparticipated/4.3-fcaj-x-aabw/images/pitch.jpg)

Suggested filenames so the layout stays consistent across events:
- `cover.jpg` — main banner/cover photo
- `teams.jpg` — all 4 teams lined up
- `pitch.jpg` — our team on stage
- `judging.jpg` — panel / Q&A moment
- `awards.jpg` — awards photo (if applicable)

Tip: keep individual files under ~1 MB so the Hugo build stays fast.
