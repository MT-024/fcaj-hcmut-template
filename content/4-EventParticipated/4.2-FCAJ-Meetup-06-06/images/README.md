Drop event photos here, then reference them from `../_index.md` and `../_index.vi.md` like:

```markdown
![Group photo at FCAJ Meetup](/4-eventparticipated/4.2-fcaj-meetup-06-06/images/group.jpg)
![Speaker session 1](/4-eventparticipated/4.2-fcaj-meetup-06-06/images/session-01.jpg)
```

Suggested filenames so the layout stays consistent across events:
- `cover.jpg` — main banner/cover photo
- `group.jpg` — group photo with other attendees
- `session-01.jpg` … `session-NN.jpg` — one per talk
- `networking.jpg` — informal hallway / networking shot

Tip: keep individual files under ~1 MB so the Hugo build stays fast.
